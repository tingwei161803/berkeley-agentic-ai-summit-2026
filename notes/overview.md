## 活動簡介 / About the Event

- **日期**:2026 年 8 月 1 日(六)– 8 月 2 日(日)
- **地點**:UC Berkeley 校園(實體票完售,另有全球直播)
- **主辦**:Berkeley RDI(Center for Responsible, Decentralized Intelligence)與 Responsible Decentralized Intelligence Foundation
- **規模**:預估約 5,000 名現場參加者(2025 年首屆為 2,000+ 現場、40,000+ 線上);延續 Agentic AI MOOC 社群(近 40,000 名學員)的動能
- **定位**:號稱最大、最完整的 Agentic AI 專題活動,涵蓋 foundation models、agent frameworks、evaluation、infrastructure 到實際部署,以及 safety & security

活動主軸:如果 2025 是「Year of Agents」,2026 則是 agentic AI 在研究、基礎設施與產業部署上更爆發性成長的一年。

*In English*: A two-day summit (Aug 1–2, 2026, UC Berkeley) hosted by Berkeley RDI — billed as the largest event dedicated to Agentic AI, spanning foundation models, agent frameworks, evaluation, infrastructure, real-world deployment, and safety & security. ~5,000 in-person attendees plus a global livestream; the 2025 edition drew 2,000+ in person and 40,000+ online.

## 整理流程 / Workflow

1. 從對照表找到該演講所在的逐字稿與影片。
2. 轉出可讀文字並定位演講起訖時間:
   ```bash
   uv run python scripts/srt_to_text.py "tmp/<檔名>.srt" --marker-interval 300 > /tmp/session.txt
   # 找到段落後,可用 --start/--end 只轉出該演講
   uv run python scripts/srt_to_text.py "tmp/<檔名>.srt" --start 00:19:29 --end 00:42:28
   ```
3. 依 [TEMPLATE.md](TEMPLATE.md) 撰寫筆記(雙語),存到 `notes/talks/<日期>-<舞台>/<講者>--<標題>.md`。
4. 重新產生索引與待確認彙整:`uv run python scripts/build_index.py`。
